## Getting Started

### Live Demo

🚀 [View Portfolio](https://KingBenice.github.io/portfolio/)

### Local Installation

1. Clone the repository:
```bash
git clone https://github.com/KingBenice/portfolio.git
cd portfolio
```

2. Open in your browser:
- Double-click `index.html` to open directly
- Or use a local server:
```bash
python -m http.server 8000
# Visit http://localhost:8000
```

## How to Customize

### Update Personal Information

1. **Name & Title** - Edit in hero section
2. **About Text** - Update about section paragraph
3. **Contact Info** - Change email, phone, location in contact section
4. **Social Links** - Update GitHub, LinkedIn, Twitter URLs

### Add New Projects

1. Duplicate a project card in the projects section
2. Update:
   - Project title
   - Description
   - Technology tags
   - GitHub and live demo links
   - Background gradient color

### Modify Skills

1. Update skill names in the skills section
2. Adjust proficiency percentages
3. Change progress bar widths (already responsive)
